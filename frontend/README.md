# Project Management MVP - Frontend

Frontend for the Project Management MVP Kanban board built with Next.js, Tailwind CSS, and @dnd-kit.

## Setup and Running

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Run unit tests:
```bash
npm test
```

Run end-to-end tests:
```bash
npm run test:e2e
```
